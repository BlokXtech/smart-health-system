# Health Management System

A simple health management system starter with:
- PostgreSQL-ready backend APIs
- Dashboard UI for analytics and appointments
- Login and registration forms
- Live time display

## Run

1. Install dependencies: npm install
2. Copy .env.example to .env and set your PostgreSQL URL.
3. Start the app: npm start

The app works in fallback mode without PostgreSQL configured, but PostgreSQL is used automatically when DATABASE_URL is present.
